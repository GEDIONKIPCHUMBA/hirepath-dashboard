# HirePath Dashboard

Full-stack scholarship management dashboard built with Next.js.

## Features
- Modern dashboard UI matching the design
- Frontend: React + Tailwind CSS
- Backend: Next.js API route at `/api/dashboard` serving scholarship & candidate data
- Mock data for scholarships, stats, and AI match alerts

## Deploy on Vercel
1. Go to [vercel.com](https://vercel.com) and import the GitHub repo `GEDIONKIPCHUMBA/hirepath-dashboard`
2. Or connect your GitHub account in Vercel settings (Login Connection) then use the dashboard to import.
3. Vercel will auto-detect Next.js and deploy.

## Local development
```bash
npm install
npm run dev
```

API endpoint: `GET /api/dashboard`
